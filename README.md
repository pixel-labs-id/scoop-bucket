# 🍨 PixelBot Scoop Bucket

Official Windows Scoop Bucket for **PixelBot** — Enterprise-grade live photo streaming and ingest engine for professional event photographers.

---

## 🚀 Installation

### 1. Add this Bucket
```powershell
scoop bucket add pixel-labs https://github.com/moedjo/scoop-bucket
```

### 2. Install PixelBot
```powershell
scoop install pixelbot
```

### 3. Run PixelBot
```powershell
pixelbot
```

---

## 🔄 Updating
To update PixelBot to the latest release:
```powershell
scoop update
scoop update pixelbot
```
